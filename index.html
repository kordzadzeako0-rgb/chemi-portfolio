ჩემს შესახებ

ასაკი: 19 წლის

ქალაქი: თბილისი, საქართველო

გამარჯობა! ვარ მეგობრული, მიზანსწრაფული და ახალი ტექნოლოგიების შესწავლით მუდმივად დაინტერესებული ახალგაზრდა. თავისუფალ დროს ხშირად ვეცნობი ციფრულ ტრენდებსა და ინოვაციებს.

პროგრამირების სწავლა გადავწყვიტე იმიტომ, რომ მჯერა ტექნოლოგიების ძალის — შექმნა რაიმე სასარგებლო და ფუნქციური ნულიდან, რაც რეალურ პრობლემებს გადაჭრის და ადამიანების ცხოვრებას გაამარტივებს.

ჩემი ჰობი

  • ხატვა: დროის გასაყვანად კარგი საშვალებაა.
  • ონლაინ თამაშები და სტრატეგიები: თამაშები მეხმარება ლოგიკური აზროვნებისა და პრობლემების სწრაფად გადაჭრის უნარის განვითარებაში.

ჩემი მიზნები

მოკლევადიანი მიზნები:

  • წარმატებით დავასრულო HTML, CSS და JavaScript-ის საბაზო და მოწინავე კურსები.
  • შევქმნა მინიმუმ 5 სრულფასოვანი სავარჯიშო ვებგვერდი ჩემი პორტფოლიოსთვის.
  • აქტიურად დავიწყო პროგრამირებაში პრაქტიკული ამოცანების ამოხსნა (მაგ. Codewars-ზე).

გრძელვადიანი მიზნები:

  • დასაქმება Junior Frontend Developer-ის პოზიციაზე და რეალურ განვითარებაზე ორიენტირებულ გუნდში ინტეგრაცია.
  • React-ისა და სხვა თანამედროვე ფრეიმვორკების სრულყოფილად ათვისება.
  • გავხდე გამოცდილი Full-Stack დეველოპერი და მივსდიო მუდმივ პროფესიულ ზრდას.

განათლება

სასწავლო დაწესებულება: კავკასიის საერთაშორისო უნივერსიტეტი

სწავლის წლები: 2024 - 2028

მიმართულება: IT

დამატებითი კურსები:

  • ვებ-დეველოპმენტის შესავალი (ონლაინ პლატფორმა, 2025)
  • Git და GitHub-ის გამოყენების საბაზო კურსი (2026)

გამოცდილება

  • სასწავლო პროექტი — „პირადი ბლოგი“: შევქმენი მარტივი, სტრუქტურული ბლოგის გვერდი სემანტიკური HTML-ის გამოყენებით.
  • გუნდური პროექტი — „ონლაინ რეცეპტების წიგნი“: თანაავტორი სტუდენტურ ჯგუფურ პროექტში, სადაც ვამზადებდით მარტივ ვებგვერდს კულინარიული რეცეპტებისთვის.
  • მოხალისეობრივი საქმიანობა: მონაწილეობა მივიღე ახალგაზრდული საგანმანათლებლო ფესტივალის ორგანიზებაში.

  • JavaScript (საბაზო ლოგიკა)
